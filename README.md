# 4D Tesseract Simulator

This project is a visual demonstration of a four-dimensional hypercube projected into 3D and then into 2D.

The main file is `index.html`, where you can interact with the simulation using controls for color, language, line thickness, and point visibility.

## How to download and run

1. Download or clone this repository.
2. Open the project folder on your computer.
3. Double-click `index.html` or open it in a web browser.
4. If you prefer, use a simple local server such as VS Code Live Server or `python -m http.server`.


# Simulador de Tesseract 4D

Este projeto é uma demonstração visual de um hipercubo em quatro dimensões projetado para 3D e depois para 2D.

O arquivo principal é `index.html`, onde é possível interagir com a simulação usando controles de cor, idioma, espessura de linha e exibição dos pontos.

## Como baixar e executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no seu computador.
3. Clique duas vezes em `index.html` ou abra-o em um navegador web.
4. Se desejar, use um servidor local simples como o Live Server do VS Code ou `python -m http.server`.
